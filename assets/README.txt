Data Center Simulation — Custom Asset Specifications
===================================================

Place your custom PNG sprites and button icons in this folder.
All assets support transparency (RGBA PNG format).
If any image file is missing, the visualizer automatically renders
high-quality procedural 2D vector fallback graphics.

1. System Architecture Nodes:
-----------------------------
  - server_active.png   (Server running with active requests) [Recommended: 70x100 px]
  - server_idle.png     (Server powered on with 0 active requests) [Recommended: 70x100 px]
  - server_boot.png     (Server cold booting / warming up) [Recommended: 70x100 px]
  - server_sleep.png    (Server in low-power ACPI standby state) [Recommended: 70x100 px]
  - server_off.png      (Server completely powered down) [Recommended: 70x100 px]
  - load_balancer.png   (Central load balancer unit) [Recommended: 100x100 px]
  - cloud.png           (Internet / WAN traffic source) [Recommended: 100x64 px]
  - packet.png          (Request document / data packet) [Recommended: 25x16 px]

2. Button & Control Icons:
-------------------------
  - icon_menu.png       (Top navigation Menu button icon) [Recommended: 20x20 px]
  - icon_play.png       (Start simulation / run button icon) [Recommended: 24x24 px]
  - icon_pause.png      (Pause simulation button icon) [Recommended: 24x24 px]
  - icon_reset.png      (Reset simulation / restart icon) [Recommended: 20x20 px]
  - icon_drop.png       (Abrupt traffic drop button icon) [Recommended: 20x20 px]
  - icon_surge.png      (Flash crowd surge trigger icon) [Recommended: 20x20 px]
  - icon_graphs.png     (Real-time oscilloscope graphs toggle icon) [Recommended: 20x20 px]
  - icon_settings.png   (Settings & hardware configuration icon) [Recommended: 20x20 px]
  - icon_close.png      (Modal close / cancel icon) [Recommended: 20x20 px]
