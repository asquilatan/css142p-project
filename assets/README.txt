Place your custom PNG sprites in this folder.
Supported sprite filenames:
  - server_active.png   (Server running with active requests)
  - server_idle.png     (Server powered on with 0 active requests)
  - server_boot.png     (Server cold booting)
  - server_sleep.png    (Server in low-power ACPI sleep state)
  - server_off.png      (Server powered down)
  - load_balancer.png   (Central load balancer unit)
  - cloud.png           (Internet / traffic source icon)
  - packet.png          (Request document / data packet)

If any image is missing, the visualizer automatically renders clean 2D vector fallback graphics.
